    Change the `toDefaults` function (lines 25-43) so the create-mode branch uses `entry?.workout_date` when provided:

    ```javascript
    function toDefaults(mode, entry) {
      if (mode === "edit" && entry) {
        return {
          workout_type: entry.workout_type || "EASY",
          workout_date: entry.workout_date || todayIso(),
    ```

## What Was Being Attempted
Testing the complete coach chat + plan patch flow. Waves 1 & 2 are production-ready (deployed). Wave 3 is code-complete but couldn't verify in browser due to JWT auth issue.

## Technical Approach
- Chat is routed through claude-coach Edge Function with `mode: "chat"`
- Payload includes hierarchical plan window (4-back, current, 6-forward weeks) + recent activities
- Claude responds with `{text, patch: null|[...], patchSummary}`
- ChangeCard component renders patches inline with Apply/Dismiss buttons
- Clicking Apply calls `hierarchicalPlan.applyPatch()` which triggers PostgreSQL RPC

## Why JWT Auth Was Failing
1. **First attempt**: ChatPanel passed Authorization header manually → conflicted with Supabase's automatic header
2. **Second attempt**: Removed manual header, but Edge Function tried to verify JWT manually using anon key → failed because anon key can't validate JWTs
3. **Third attempt** (deployed v6): Removed manual verification, relying on Supabase's `verify_jwt: true` flag which automatically validates before function runs
4. **Environment issue**: Dev server was on 5181 (wrong project `HandleAppen`), causing module resolution issues

## Typography

Source: pa-tokens.css, DESIGN.md Section 3, REQUIREMENTS.md DSGN-02

Phase 14 uses 4 type roles. Two fonts, two weights. All text colors use `--pa-on-surface` or `--pa-on-surface-variant` — never pure black.

| Role | Font | CSS Var | Size | Weight | Line Height | Usage |
|------|------|---------|------|--------|-------------|-------|
| Display metric | Manrope | `--pa-text-display-sm` | 24px / 1.5rem | 700 | 1.2 | NOT used in Phase 14 (deferred to volume trend header, Phase 16) |
| Headline | Manrope | `--pa-text-headline-md` | 18px / 1.125rem | 700 | 1.2 | Load column km readout (primary metric) |
| Body | Inter | `--pa-text-body-md` | 14px / 0.875rem | 400 | 1.5 | Workout card type label |
| Label | Inter | `--pa-text-label-md` | 12px / 0.75rem | 400 | 1.4 | Date labels, secondary metrics (hours/minutes), constraint reason |
| Label small | Inter | `--pa-text-label-sm` | 11px / 0.6875rem | 400 | 1.4 | Day cell date label, workout description clip line, load column time readout, empty cell affordance hint |

Active type roles for this phase: Headline + Body + Label + Label small (4 roles, 2 fonts, 2 weights: 400 regular + 700 bold).

**Note on 11px/12px proximity:** Label small (11px) and Label (12px) are 1px apart. Visual distinction is maintained because they never appear side-by-side in the same typographic run — 11px is used for subordinate/secondary content (description clip, time readout) and 12px for primary labeling (type name, date label). The semantic role difference, not the size delta, creates hierarchy.

**Weight rule:** Two numerically distinct weights only — 400 (regular) and 700 (bold). Do not use 600 anywhere in Phase 14. All "bold" text uses `font-weight: 700`.

**Specific applications:**

- Day cell date label ("12. OKT"): 11px (`--pa-text-label-sm`), weight 700, color `--pa-on-surface-variant`, uppercase, Inter
- Workout card type name: 12px (`--pa-text-label-md`), weight 700, color via `--pa-type-*` token, Inter
- Workout card description line: 11px (`--pa-text-label-sm`), weight 400, opacity 70%, color via `--pa-type-*` token, Inter — single line, `truncate`
- Load column km: 14px (`--pa-text-body-md`), weight 700, color `--pa-on-surface`, Manrope — leads visually
- Load column hours/minutes: 11px (`--pa-text-label-sm`), weight 400, color `--pa-on-surface-variant`, Inter — subordinate
- Empty day cell add affordance: 11px (`--pa-text-label-sm`), weight 400, color `--pa-on-surface-variant` at 40% opacity, Inter
- Rest day label: 11px (`--pa-text-label-sm`), weight 400, color `--pa-type-rest`, Inter
- Race card label: 12px (`--pa-text-label-md`), weight 700, color `#fff`, Inter

## Color

Source: pa-tokens.css, DESIGN.md (No-Line Rule, Surface Hierarchy), REQUIREMENTS.md DSGN-01/03

### Surface Hierarchy (60/30/10)

| Role | Token | Value | Usage |
|------|-------|-------|-------|
| Dominant (60%) | `--pa-surface` | #f8f9fa | Page background, grid canvas |
| Secondary (30%) | `--pa-surface-container-low` | #f3f4f5 | Load column background (slightly distinct from day cells) |
| Primary card surface | `--pa-surface-container-lowest` | #ffffff | Day cell background (highest contrast "lift") |
| Accent (10%) | `--pa-primary` | #003371 | Today highlight ring, add affordance icon |
| Destructive | n/a | n/a | No destructive actions in Phase 14 (edit/delete deferred to Phase 15) |

**Accent reserved for:** today-ring highlight only, add-affordance "+" icon color. Do not use `--pa-primary` for workout cards, backgrounds, or generic interactions in this phase.

### Workout Type Color Map (from Phase 13 — canonical)

| Type | Accent token | Container token | Hex (accent) | Hex (container) |
|------|-------------|-----------------|--------------|-----------------|
| EASY / RECOVERY | `--pa-type-easy` | `--pa-type-easy-container` | #3b82f6 | #eff6ff |
| TEMPO / INTERVALS / STEADY_STATE | `--pa-type-hard` | `--pa-type-hard-container` | #003371 | #e0e9f5 |
| LONG_RUN | `--pa-type-endurance` | `--pa-type-endurance-container` | #f59e0b | #fef3c7 |
| REST | `--pa-type-rest` | `--pa-type-rest-container` | #94a3b8 | #f1f5f9 |
| RACE_EVENT | `--pa-type-race` | `--pa-type-race-container` | #d4af37 | #fff9e6 |
| STRENGTH / CROSS_TRAIN | `--pa-type-other` | `--pa-type-other-container` | #0d9488 | #f0fdfa |

All workout card backgrounds use the `-container` token. Left border accent stripe uses the base token. Never write hex values inline — always use `var(--pa-type-*)`.

### Load Status Colors

| Status | Color | Application |
|--------|-------|-------------|
| on-target | `--pa-type-endurance` (#f59e0b) | StatusDot — amber = normal load |
| over-target | `--pa-type-hard` (#003371) | StatusDot — navy = above target |
| empty (0 km) | `--pa-on-surface-variant` at 30% opacity | "—" dash in load column |

Note: Status is color-only, no text label (CONTEXT.md decision).

### No-Line Rule (DESIGN.md — strictly enforced)

- Never use `border: 1px solid` anywhere in Phase 14 components.
- Day cell separation: achieved through `--pa-surface-container-lowest` cards on `--pa-surface` canvas with `--pa-space-4` (16px) gap between columns.
- Load column distinction from day cells: achieved through `--pa-surface-container-low` background — one tone step darker, no border.
- Constraint marker: use `border-dashed` at 1px only for the constraint-only cell outline (no workout present) — this is a semantic signal, not a decorative border. This is the single exception to the No-Line Rule, permitted because it is a data state indicator.

### Today Highlight

- Day cell with `isoDate === todayIso()`: add `ring-2` at `--pa-primary` color, 20% opacity (`ring-pa-primary/20` or `box-shadow: 0 0 0 2px rgba(0, 51, 113, 0.20)`).
- Do not change the cell background for today — ring-only treatment.

## Interaction States

Source: 14-CONTEXT.md decisions

### Desktop DayCell

| State | Visual Treatment |
|-------|-----------------|

## Layout Contract

### Desktop Grid

```
[FourWeekGrid — space-y-24px between rows]
  [WeekRow — grid-cols-12, gap-16px]
    [DayCell × 7 — col-span-11 inner grid-cols-7]  [LoadColumn — col-span-1]
    [DayCell min-h: 140px, p-12px, rounded-12px]
```

- Grid starts at `currentMondayIso()` — no navigation controls in Phase 14
- Breakpoint: below 900px, the desktop grid is hidden; mobile pager is shown
- Grid outer padding: 32px horizontal (`--pa-space-8`)

### Mobile Layout

```
[MobilePlannerPager]
  [MobileWeekStrip — horizontal day tabs + prev/next arrows]
  [MobileDayPanel — stacked WorkoutCards for selected day]
  [MobileLoadSummary — inline km + hours, no stacked bar]
```

- One week visible at a time
- Week switching: swipe gesture or prev/next tap
- Day selection: tap on day tab opens drill-in panel below
- MobileLoadSummary: single line "X km · Xh Xm", no stacked bar column

## Copywriting Contract

Source: REQUIREMENTS.md requirements text, CONTEXT.md, Norwegian user base (RESEARCH.md Pattern 5)

| Element | Copy | Notes |
|---------|------|-------|
| Add affordance (empty cell) | "+" (icon only) | No text label; hover tooltip: "Legg til økt" (Add workout) — wired in Phase 15 |
| Empty day cell — no affordance | (blank) | Empty cells show only the add affordance icon |
| Empty week load | "—" | Single em-dash, no label |
| Load column km label | "{N} km" | Number then unit, bold, no decimals for values ≥ 10km; one decimal for < 10km |
| Load column time label | "{N}h {N}m" or "{N}m" | Hours omitted when zero (e.g., "45m" not "0h 45m") |
| Rest day card label | "Hviledag" | Norwegian — matches app locale convention |
| Race card label | Entry description or "Løp / Arrangement" | Use `entry.description` if present; fallback to Norwegian default |
| Constraint marker label | (icon only in Phase 14) | CNST-01 (reason text) deferred to Future Requirements; show `AlertCircle` icon only |
| Mobile week label | "Uke {N}" | E.g., "Uke 13" — ISO week number |
| Mobile load summary | "{N} km · {time}" | Compact single-line format |

**Error states in Phase 14:**

Phase 14 is a read-only display phase (no create/edit/delete). The only error state is a data-load failure.

| Element | Copy |
|---------|------|
| Grid load error | "Kunne ikke laste treningsplan. Prøv igjen." |
| Grid loading skeleton | Day cells show muted placeholder blocks (no text) |

**No destructive actions in Phase 14.** Create/edit/delete belongs to Phase 15.

## Anti-Patterns (Phase 14 Enforced)

Derived from RESEARCH.md anti-patterns section:

1. Never write `style={{ background: "#003371" }}` for workout type colors. Always use `var(--pa-type-*)`.
2. Never add `border: 1px solid` to day cells or load column (No-Line Rule from DESIGN.md).
3. Never call `loadEntriesForWeek` four times. Use `loadEntriesForRange` once for the 28-day window.
4. Never run `computeWeeklyLoadStats` in render directly. Wrap with `useMemo` keyed on the week's entries array.
5. Never use the local `WORKOUT_TYPES` array in `WeeklyPlanPage.jsx` (line 13) or `MobilePage.jsx` (line 11) for card rendering. Use `WORKOUT_TYPES` from `src/domain/workoutTypes.js`.
6. Never duplicate `currentMondayIso()` / `isoDateOffset()` into new components. Move to `src/lib/dateUtils.js`.
7. Never use `font-weight: 600` in Phase 14 components. The single bold weight is 700.
8. Never use `text-[10px]` in Phase 14 components. All text at or below 11px uses `--pa-text-label-sm` (11px).
